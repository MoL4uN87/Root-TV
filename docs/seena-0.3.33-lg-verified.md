# Seena webOS 0.3.33 — проверено на LG TV

23 октября 2026 пользователь подтвердил ручную проверку на реальном LG webOS.

## Проверенные изменения

- Касание кадра YouTube-трейлера переключает видимость нижнего меню Seena без приостановки воспроизведения.
- Верхняя панель webOS с отдельной кнопкой «Назад» скрывается только во время встроенного YouTube-трейлера, сам iframe занимает доступную высоту.
- Перемотка, Play/Pause, выбор трейлеров, доступ к качеству и выход назад сохранены.
- Остальные онлайн-плееры сохраняют обычную верхнюю панель.

## Сборка

IPK `com.seena.webos_0.3.33_all.ipk` со скрытой верхней панелью был успешно собран командой `ares-package`, скопирован на телевизор с контролем SHA-256 и установлен. Проверенная контрольная сумма IPK:

`4b878445da83eefa200dab8f6a92b564bed2f51f42e9dd0c9dd7054a617dc0f6`

Подтверждение пользователем: «все работает».

Для воспроизводимого релиза **необходимо сохранить на GitHub сами исходники из локальной папки резервной копии TV**, поскольку базовые исходники webOS в `main` предшествовали этой функциональности. Для этого предусмотрен ограниченный allowlist-скрипт `scripts/publish-tested-webos-sources.ps1`. Не добавлять в Git публичного репозитория cookies, `kinozal-config.json`, `*.bak`, личные учётные записи, VPN-настройки и готовые IPK, содержащие личную конфигурацию.

Полный исходный архив приложения и локальная резервная копия остаются на компьютере пользователя. Сохранение исходников не должно менять установленное приложение.
