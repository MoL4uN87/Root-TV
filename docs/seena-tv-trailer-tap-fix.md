# Seena LG webOS 0.3.33 — управление трейлерами

Эта правка предназначена **только** для версии webOS, скопированной с установленного LG TV 23.10.2026. Исходная Android Seena не изменяется.

## Причина
В `trailer-youtube.html` видео работает через вложенный YouTube iframe. Когда клик доставляется этому iframe, YouTube может переключать воспроизведение вместо скрытия панели Seena.

## Исправление
Скрипт `scripts/build-live-seena-trailer-ipk.ps1` выполняет проверяемую, повторно безопасную правку **локального** `trailer-youtube.html`. Прозрачный слой принимает клики в области кадра и переключает только `#remote-controls[hidden]`; он оставляет нижние 55px YouTube для нативных кнопок и ⚙. Кнопка Play/Pause, специальные медиа-клавиши, таймлайн, выбор русской версии и подсказки качества сохранены.

Нажатие OK/пробела, когда выбран фон кадра, показывает/скрывает меню. Нажатие OK на выбранной кнопке активирует её. Отключённый автозапуск показывает панель и выбирает кнопку запуска.

## Безопасная сборка
Вначале создать резервную копию с ТВ. Она должна включать актуальную папку `app/` целиком, включая `mma-sources.js`, а также `appinfo.json` с версией `0.3.33`.

После загрузки скрипта из ветки `fix/webos-trailer-controls` выполнить:

```powershell
& .\build-live-seena-trailer-ipk.ps1 -BackupRoot "$HOME\Documents\ChatGPT\Seena-WebOS-Backup-20261023-212502"
```

Скрипт резервирует оригинальный HTML, проверяет синтаксис JS, собирает чистую папку с разрешёнными файлами и запускает `ares-package`. **Установки на ТВ не происходит.**

Не публиковать и не включать в IPK: `kinozal-config.json`, `*.bak*`, `cookies.json`, `account.json`, приватные ключи и VPN-конфигурации.

Проверка на PC после исправления:

```powershell
node tests/live-tv-trailer-hud.test.cjs "$HOME\Documents\ChatGPT\Seena-WebOS-Backup-20261023-212502\app\trailer-youtube.html"
```

Никаких гарантированных результатов работы на физическом телевизоре до установки и ручной проверки не заявляется. Исходный `app.js` из GitHub main **старее**, чем установленный на ТВ, поэтому сборка напрямую из main не допускается.
