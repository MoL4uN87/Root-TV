# YouTube AdFree 1.1.7 для LG webOS (ARM)

Резервная копия **установленного приложения** `com.cobalt.youtube.adfree`, снятая через SSH с LG webOS.

## Варианты резервной копии

Планируются два файла в разделе **Releases** этого репозитория:

- `youtube-adfree-1.1.7-prebuild-sanitized.zip` — очищенные файлы приложения **до упаковки** в IPK. Это не исходный код проекта Cobalt, а копия установленного приложения, включая бинарные компоненты.
- `com.cobalt.youtube.adfree_1.1.7_arm.ipk` — установочный пакет для совместимых телевизоров LG webOS с ARM.

Файлы релиза нужно загружать только после проверки отсутствия персональных данных. **Документ не означает, что файлы уже опубликованы.**

## Установка IPK

Подключите целевой телевизор через Developer Mode или совместимый SSH-доступ, настройте его в webOS CLI (имя `TV2` ниже — пример). Затем выполните в PowerShell:

```powershell
ares-install -d TV2 ".\com.cobalt.youtube.adfree_1.1.7_arm.ipk"
```

На другом телевизоре потребуются подходящая версия webOS, ARM-архитектура и, возможно, root/homebrew-компоненты. Сам факт успешной сборки IPK не гарантирует его работы.

## Сборка из очищенной копии

Если распакованная папка называется `com.cobalt.youtube.adfree`:

```powershell
ares-package --no-minify -o .\IPK .\com.cobalt.youtube.adfree
```

## Приватность

**Не публикуйте** содержимое `.config/`, `storage/`, `tmp/`, файлы `cookie`, `settings.dat`, `*.storage`, ключи, токены, данные учётных записей и иные пользовательские данные. Исключения при упаковке не заменяют проверку архива.

## Права

Приложение содержит сторонние компоненты, в том числе Cobalt. Перед публичным распространением бинарных файлов и модификаций необходимо проверить соответствующие лицензии и права на распространение.
